## 📊 Cómo Usar las Nuevas Funcionalidades

### Redimensionar Plot
1. Pasa el mouse por la **parte inferior del plot**
2. Verás aparecer una línea de color (el handle)
3. **Click y arrastra** hacia abajo para agrandar
4. El plot se redibuja automáticamente

### Mover Leyenda
1. Haz click en el **cuadro de la leyenda** (fondo blanco)
2. **Arrastra** a cualquier posición dentro del plot
3. Suelta donde quieras que quede

### Exportar
- **SVG**: Para incluir en LaTeX con `\includesvg{plot.svg}`
- **PNG**: Para Word, PowerPoint, o journals que no aceptan SVG
